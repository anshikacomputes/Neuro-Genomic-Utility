# Neuro-Genomic Motif Utility
**Author:** Anshika Mishra  
**Field:** Computational Genetics / Neurobiology

## Project Overview
This Python-based utility is designed to automate the initial analysis of genomic sequences. In neurobiology research, identifying specific regulatory patterns (motifs) is crucial for understanding gene expression in neurodegenerative diseases. This tool provides a rapid way to check sequence stability and locate key binding sites.

## Key Features
* **GC-Content Analysis:** Calculates the percentage of Guanine and Cytosine to assess DNA thermal stability, essential for PCR primer design.
* **Start Codon Mapping:** Automatically locates the translation initiation site (ATG).
* **Motif Identification:** Searches for user-defined regulatory sequences (e.g., transcription factor binding sites) within raw genomic data.

## Biological Significance
By transitioning from manual sequence inspection to automated Python scripts, this project demonstrates a workflow for handling high-throughput genomic data. It bridges the gap between traditional Zoology studies and modern Bioinformatics.
